# map-procedural-generation-terrain — rules

Combine with the root CLAUDE.md. This is **THE standalone base terrain generator** for the whole world — run it first, it must keep working on its own. Voronoi biomes + height/moisture noise + grid-aligned vegetation → ONE big base map `dest/map/main/<maincode>/all.tmx` (e.g. 176×176, **CSV**-encoded; layers `Water`/`Walkable`/`Grass`/`OnGrass*`/`LedgesDown|Left|Right`). The sibling `../map-procedural-generation/` then CHUNKS `all.tmx` into per-map zlib `.tmx` and adds cities/roads/bots/encounters on top — it does NOT regenerate terrain.

* **RIGID, RECTANGULAR, grid-aligned feature BLOCKS — never scattered/organic.** Grass, trees, water, ledges are solid grid-aligned rectangles (`doc/mapping/Goodmap.png` good vs `Badmap.png` bad): it IS the classic GBA-era tile-RPG style AND compresses far better (long runs of one gid). **The grass here is already correct — leave it rigid.** NEVER thin a feature zone with per-cell noise to look "natural" (that is the Badmap mistake), here or downstream.
* **`TerrainShaper` is the ONLY hook on the raw height/moisure noise** (called from `LoadMap::addTerrain`, `addPolygoneTerrain`, `MiniMap`). Base class = noise untouched, so this tool is byte-identical without it; a downstream tool `setActive()`s a derived one. It receives world TILE coords — the voronoi grid is stored scaled by `VoronioForTiledMapTmx::SCALE`.
* **Stays standalone, and runs OUT OF THE BOX.** `cmake -S . -B <build> && cmake --build <build> && <build>/map-procedural-generation-terrain` — no argument, no manual copy. The `-runtime` target links `template/` + `tileset/` and `settings.ini` next to the binary; `main()` then stages `tileset/` into the `dest/map/tileset/` + `dest/map/main/tileset/` run pool (`LoadMap::stageTilesetPool`) and CREATES `dest/map/main/<maincode>/` **before any template is read** — the template tilesets resolve as `<label dir>/../../tileset/x.tsx` and the kernel cannot walk `..` through a directory that does not exist. Tileset names in `settings.ini` must match what `tileset/` ships (`animations.tsx`, `terra.tsx`, `wood.tsx`, `invisible.tsx`). Never write tilesets back into a source datapack tree (read-only).
